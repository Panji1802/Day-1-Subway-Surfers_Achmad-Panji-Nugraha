## DOKUMENTASI KEGIATAN WORKSHOP-DAY1

### 1. Apa Tujuan Workshop ini
Workshop ini dirancang untuk membekali mahasiswa baru TIK PNJ dalam menyikapi transisi ke dunia perkuliahan. Diajak memahami karakter pembelajaran perkuliahan, tips menjaga keseimbangan antara akademik dan organisasi, serta pemanfaatan teknologi dasar yang efisien untuk membantu siap beradaptasi sejak semester awal.

---

### 2. Rangkuman Materi Workshop
* **Arah Strategis & Roadmap JTIK (2026–2030):** Menjelaskan visi JTIK menuju jurusan bertaraf internasional melalui pendidikan vokasi berbasis kurikulum OBE, peningkatan riset terapan, serta penguatan inkubator bisnis dan kerja sama industri.
* **Struktur Jurusan & Kurikulum:** Pengenalan program studi (TI, TMJ, TMD, RKS) beserta alur pemetaan mata kuliah dari dasar komputasi hingga magang dan tugas akhir.
* **Sistem Pembelajaran & Metode Belajar:** Penerapan metode *Project-Based Learning* (PjBL) dan *Case-Based Learning* (CBL), serta tips belajar efektif bertahan lama (*retrieval practice*, *spaced practice*) mengacu pada riset *Make It Stick*.
* **Tata Tertib & Prosedur Kampus:** Penjelasan aturan kerapian berbusana/rambut, sanksi pelanggaran akademik, alur peminjaman alat lab, serta peminjaman ruangan lab.
* **Program MBKM & MSIB:** Kesempatan mahasiswa mengambil hak belajar hingga 2 semester di luar prodi/kampus dengan konversi hingga 20 SKS per semester.

---

### 3. Poin-Poin Penting yang Didapat Hari Ini
* **A. Peran GitHub untuk Kolaborasi:** GitHub adalah platform berbasis web yang digunakan untuk menyimpan repositori Git secara daring sekaligus memfasilitasi kerja sama tim dalam pengembangan kode.
* **B. Alur Kerja Git Lokal:** Pengelolaan versi kode melewati tiga area utama, yakni *Working Directory* (area kerja), *Staging Area* (penampungan sementara), hingga direktori repositori Git.
* **C. Perintah Dasar Git dan Sinkronisasi:** Proses pencatatan dan pengunggahan data menggunakan perintah dasar seperti `git init`, `git add`, `git commit`, serta perintah sinkronisasi seperti `git push` dan `git pull`.
* **D. Keamanan Akses Menggunakan SSH:** Autentikasi ke GitHub dapat diamankan menggunakan kunci SSH agar proses penghubungan sistem berjalan aman tanpa kendala kredensial manual berulang.
* **E. Prosedur Layanan Laboratorium:** Alur administrasi di laboratorium mencakup tata cara baku peminjaman ruangan maupun peminjaman alat (baik untuk penggunaan langsung di lab maupun dibawa pulang) melalui konfirmasi teknisi dan persetujuan Kepala Laboratorium.
* **F. Struktur Kurikulum Akademik:** Program studi memiliki susunan mata kuliah per semester yang mencakup perimbangan antara porsi teori dan praktik (seperti pengenalan dasar teknologi, jaringan, pemrograman, hingga keamanan siber).
* **G. Integrasi Proyek Praktis:** Rangkaian pembelajaran diakhiri dengan praktik langsung membuat aplikasi atau proyek berbasis web menggunakan bantuan platform AI, yang kemudian dikelola versinya serta diunggah ke GitHub.

### 4. Kesan & Pesan Mengenai Workshop Day-1
Secara keseluruhan, workshop ini memberikan kesan yang sangat positif dan membuka wawasan baru, khususnya dalam menggabungkan teknologi modern seperti kecerdasan buatan (AI) dengan manajemen proyek yang rapi. Pesan yang paling berkesan dari materi ini adalah bagaimana kita diajak untuk tidak hanya mengandalkan AI secara instan, tetapi juga bagaimana menyusun perintah (*prompting*) yang terstruktur agar hasilnya benar-benar sesuai dengan kebutuhan nyata di dunia industri.
